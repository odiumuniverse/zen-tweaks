# Fullscreen Sidebar

In compact mode, Zen hides the sidebar while a video is fullscreen. This mod brings it back: move the pointer to the left edge of the screen and the sidebar slides out over the video, the way it does in Arc. Move away and it hides again.

Works with the sidebar on the left. The styles are the same as in [Zen Tweaks](https://github.com/odiumuniverse/zen-tweaks), which adds two more tweaks that a CSS mod can't do.

## Submitting to the Zen mod store

Open a [Submit a theme](https://github.com/zen-browser/theme-store/issues/new?template=create-theme.yml) issue in `zen-browser/theme-store` with:

| Field | Value |
|---|---|
| Name | `Fullscreen Sidebar` |
| Description | `Slide the compact-mode sidebar out over fullscreen video by hovering the left edge, like Arc.` |
| Homepage | `https://github.com/odiumuniverse/zen-tweaks` |
| Image | a PNG screenshot of the sidebar over a fullscreen video |
| Type | leave unchecked: this is not a JSON color theme |
| Theme Styles | the contents of [`extension/fullscreen-sidebar.css`](../extension/fullscreen-sidebar.css) |
| Readme | this file down to this section |
| Preferences | leave empty |
